# iconectando — landing page premium

## Archivos
- `index.html`: landing page completa, responsive y con estilos/JavaScript integrados.
- `logo.png`: logotipo original de iconectando.
- `favicon.png`: icono del sitio.

## Publicar en GitHub Pages
1. Crea un repositorio público en GitHub (por ejemplo, `iconectando`).
2. Sube estos tres archivos a la raíz del repositorio.
3. Entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`, y guarda.
6. GitHub publicará el sitio en `https://TU-USUARIO.github.io/iconectando/`.

## Conectar un dominio propio
1. En **Settings → Pages → Custom domain**, escribe el dominio exacto que tengas registrado (por ejemplo, `www.tudominio.com`) y guarda.
2. Configura los DNS en el proveedor donde administras el dominio siguiendo la guía oficial de GitHub:
   https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site
3. Espera la propagación DNS y activa **Enforce HTTPS** cuando GitHub lo permita.
4. Si vas a usar un dominio raíz y `www`, configura ambos según las instrucciones de GitHub para tu proveedor DNS.

No se incluye un archivo `CNAME` porque el dominio definitivo debe confirmarse antes de configurarlo.
